# CLAUDE.md

Git and GitHub workflows come from the claude-tools plugins (`/git:commit`, `/git:pr`, `/git:merge-pr`,
`/git:issue`, `/git:release`, `/git:clean-branches`, `/dev:codebase-analysis`).

- Don't add `Co-Authored-By` trailers, "Generated with" lines or any other AI attribution to commits, PRs or issues.
